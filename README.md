CineVerse — Site de Cinema

Projeto desenvolvido por mim aos 15 anos como parte de uma atividade educacional do Instituto Federal de São Paulo (IFSP), durante minha jornada de aprendizado em desenvolvimento web.

Sobre o projeto

O CineVerse é um site dedicado ao universo cinematográfico, desenvolvido para apresentar informações sobre filmes de maneira organizada, visualmente agradável e intuitiva.

Funcionalidades

- Página inicial com apresentação do projeto.
- Exibição de filmes com imagens e informações.
- Página de sinopses com descrições dos filmes.
- Organização dos conteúdos em cards.
- Navegação entre as páginas do site.
- Estilização e padronização visual dos elementos.

Tecnologias utilizadas

- HTML5
- CSS3

Objetivo

Aplicar os conhecimentos adquiridos durante as atividades do IFSP, praticando estruturação de páginas com HTML, estilização com CSS, organização de conteúdos e desenvolvimento de interfaces web.

O projeto também contribuiu para aprimorar minhas habilidades de planejamento, organização, atenção aos detalhes e resolução de problemas.
